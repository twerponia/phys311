The file layout you should actually submit

This page is deliberately one file so it runs anywhere. Lab 8 wants modules. Split it like this and the Week 9 refactor costs you nothing:

labs/lab08/
  index.html
  style.css
  main.js              // wiring only: build scene, start the loop
  engine/              // NO ctx, NO canvas, NO document in here
    vec2.js            // Vec2
    body.js            // Body
    forces.js          // Gravity, Spring, Drag
    integrators.js     // Euler, EulerCromer, VelocityVerlet
    world.js           // World
  render/              // NEVER modifies a body's state
    camera.js          // metres <-> pixels, owns the y-flip
    renderer.js        // all ctx.* drawing
💡 The layering rule, stated once and enforced all semester. Nothing in engine/ may mention canvas, ctx, or document. Nothing in render/ may modify a body's state. The runHeadless() function above is proof that it pays off: it runs 15,080 physics steps with no canvas at all. In Week 13 the same trick makes your required convergence study about twenty lines. Blur the boundary and you will be untangling a renderer under deadline pressure in Week 12.

🔬 The debugging order that works. (1) Read the console — the actual error, not the first red line. (2) Network tab: did every .js load, or did one 404? (3) console.log one body's position for the first three steps and compare against the notebook. (4) Only then look at the drawing code.
